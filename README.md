# Retail-Demand-Forecasting-System-Data-Science-Project
Built an end-to-end demand forecasting project using Python, SQL, Machine Learning, and Power BI to analyze historical sales patterns and predict future product demand. Implemented time-series techniques including ARIMA and SARIMA, along with Random Forest and XGBoost models, and created an interactive Power BI dashboard for business insights.

## PROJECT OVERVIEW
Built an end-to-end Retail Demand Forecasting System to analyze historical sales data, identify demand patterns, and predict future product demand. The project combines Python, SQL, Machine Learning, Time Series Forecasting, and Power BI to turn sales data into actionable business insights.

## OBJECTIVES
1. Analyze historical retail sales and demand patterns
2. Identify trends, seasonality, and outliers
3. Create lag and rolling-window features
4. Forecast future product demand
5. Compare different forecasting and machine learning models
6. Build an interactive Power BI dashboard for business insights

## TECHNOLOGIES USED
PYTHON – Data cleaning, EDA, feature engineering and modeling
PANDAS & NUMPY – Data manipulation
MATPLOTLIB & SEABORN – Data visualization
SQL – Data analysis and querying
SCIKIT-LEARN  – Machine Learning
XGBOOST – Demand prediction
ARIMA & SARIMA – Time Series Forecasting
POWER BI – Interactive dashboard

## PROJECT WORKFLOW
Data Collection → Data Cleaning → Exploratory Data Analysis → Feature Engineering → SQL Analysis → Time Series Forecasting → Machine Learning → Model Evaluation → Power BI Dashboard

## MODELS USED

### TIME SERIES MODELS

### MACHINE LEARNING MODELS

The models were evaluated using:
